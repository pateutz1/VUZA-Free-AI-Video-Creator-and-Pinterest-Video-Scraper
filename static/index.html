VUZA

Video Utility for Zero-cost Automation

Paste a topic or narration script. VUZA finds stock footage, writes search keywords, generates voiceover, adds subtitles, and assembles a short video.

Defaults: Mixkit stock, Chinese suspense template still available, Edge TTS, high-retention captions, 9:16 output.
AI scripts in multiple languages
Batch multiple scripts
Mixkit free stock video + music
Pexels, Pixabay, and Coverr
Edge TTS + ElevenLabs
High-retention captions
Filters, transitions, and BGM
9:16, 16:9, and 1:1
OpenAI-compatible LLM gateways
Runs locally on modest PCs

How to use: add an AI text key in API settings, pick Pinterest/Pexels/Pixabay/Coverr, paste a script, then click Generate.

🔒 Keys stay in this browser. They are only sent to the APIs you configure.

AI API (OpenRouter / DeepSeek / OpenAI-compatible)

Pick a provider. Only that key, model, and Test API are shown. Other providers stay saved when you switch.

Volcengine Ark is not supported. Use OpenAI, DeepSeek, Groq, Ollama, OneAPI, or any OpenAI-compatible gateway.

Comma-separated 1–3 word English stock terms. Count = ceil(narration seconds / (Assets per scene × Clip duration)), max 15. Each term gets that many clips. Check Match visuals for chronological place/beat terms.

Media source

    Round-Robin searches Mixkit, Pexels, Pixabay, and Coverr together per scene and blends the best matches. Requires narration script mode + video type; add API keys for any providers you have.

    Mixkit is free stock video (no API key). It has no photo library — Photos switches to Videos automatically.

    Provider fallback

    Off = only the source you picked. On = if that source cannot cover narration, try the next stock provider in order.
